# Report: читаемость таблицы CA при большом числе выпущенных сертификатов

- **Дата:** 2026-10-07
- **Профиль:** bugfix (ui)
- **Статус:** Done

## Задача

В разделе Certificate Authorities, если на ЦА выпущено много сертификатов,
строка таблицы разрастается: в колонке имени выводится весь список CN через
запятую, и таблица становится нечитаемой (строки по несколько сотен
пикселей высотой).

## Решение

`frontend/src/components/CATab.vue`:

- В колонке имени показываются первые **3** имени сертификатов, остальное —
  счётчиком: `name-a, name-b, name-c +142` (числовой суффикс не требует
  локализации).
- Полный список доступен в tooltip (`title` нативный, без обёрток).
- CSS: список ограничен двумя строками (`-webkit-line-clamp: 2`) и
  `max-width: 420px` с `word-break` — длинные доменные имена не растягивают
  колонку; высота строки становится предсказуемой.

Данные (`certsByCaId`) не менялись — только отображение.

## Изменённые файлы

| Файл | Что |
|---|---|
| `frontend/src/components/CATab.vue` | `caCertsSummary` (превью 3 + счётчик), tooltip с полным списком, clamp-стили |

## Validation

- `vue-tsc` + `vite build` — зелёные; vitest не затронут (36/36 ранее)
- Сортировка/поиск таблицы не задеты: фильтруются по `name.cn`, счётчик —
  только в подписи

## Ограничения (зафиксировано осознанно)

1. Полный список по-прежнему передаётся в DOM-атрибуте `title` — при
   сотнях имён это заметный атрибут, но создаётся один раз на строку и
   лениво показывается браузером; осознанно не заменял на поповер, чтобы
   не тянуть интерактив.
2. Порог превью (3) захардкожен как `CA_CERTS_PREVIEW`.
