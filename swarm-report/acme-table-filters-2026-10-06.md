# Report: поиск, фильтры и пагинация в таблицах ACME (Accounts и Orders)

- **Дата:** 2026-10-06
- **Профиль:** ui-feature
- **Статус:** Done

## Задача

На странице ACME таблицы Accounts и Orders должны получить фильтры, поиск
(по домену / названию) и пагинацию с выбором размера страницы 15/30 —
сертификатов и заказов со временем станет много.

## Решение

Только фронтенд (`frontend/src/components/AcmeTab.vue`), UI-паттерны
скопированы с OverviewTab (поиск с иконкой, Select с showClear,
`.vt-search-wrap`/`.vt-filter-row`):

- **Обе таблицы**: `paginator` с `:rows="rowsPerPage"` (по умолчанию 15) и
  `:rowsPerPageOptions="[15, 30]"`.
- **Accounts**: поиск (имя, домены из allowlist, id) + Select фильтра по
  статусу (набор статусов строится динамически из данных, подписи через
  `acme.<status>` с фолбэком на сырое значение). Явно выбранный статус
  имеет приоритет над чекбоксом «hide deactivated»: выбрав `deactivated`,
  видно деактивированные даже при включённом чекбоксе (раньше чекбокс
  фильтровал безусловно).
- **Orders**: поиск покрывает домены (по всем `identifiers`), имя аккаунта,
  id заказа и текст ошибки; Select фильтра по статусу (динамически:
  pending/ready/valid/invalid/...). Обычный `globalFilterFields` DataTable
  не матчит вложенные массивы идентификаторов, поэтому фильтрация сделана
  в computed (`ordersTableRows`), а не средствами DataTable.
- Фильтрация в computed (`accountsTableRows` / `ordersTableRows`),
  DataTable получает уже отфильтрованный список; store не изменяется.

Локали не расширялись: переиспользованы `common.search`, `acme.colStatus`,
`acme.<status>`.

## Validation

- `vue-tsc` + `vite build` + vitest 36/36 — зелёные
- Поведение: пустой поиск/фильтр — таблицы как раньше; поиск регистро-
  нечувствительный; пагинация 15 по умолчанию, переключение на 30 на лету

## Ограничения (зафиксировано осознанно)

1. Фильтрация клиентская — по уже загруженным данным (как и весь список);
   при тысячах заказов потребуется серверная пагинация, сейчас не делалась.
2. Подписи статусов зависят от наличия ключей `acme.<status>` в локалях,
   неизвестные статусы показываются как есть.
