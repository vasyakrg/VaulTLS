# Report: фильтр CA на странице Certificates и дефолт «hide ACME certs»

- **Дата:** 2026-10-06
- **Профиль:** bugfix (ui)
- **Статус:** Done

## Задача

1. В фильтре CA на странице Certificates показываются только импортированные
   CA, внутренние отсутствуют.
2. Чекбокс «hide ACME certs» должен по умолчанию быть включён.

## Диагноз и решение

**Фильтр CA** (`OverviewTab.vue::caFilterOptions`) строился из эмиттеров
только тех сертификатов, что сейчас загружены в списке (`certificates`):
CA без сертификатов в списке — например, свежесозданная внутренняя CA или
CA, чьи серты скрыты — в фильтр не попадала вовсе.

Теперь фильтр строится из **полного списка CA** (`caStore.cas` — и внутренние,
и импортированные) + ACME-провайдеров; эмиттеры из сертификатов добавляются
как fallback (например, провайдер у не-админа, у которого список провайдеров
не загружается). Метки CA — в формате «CN (ID: N)», как в модалке генерации,
чтобы различать CA с одинаковым CN.

**hideAcmeCerts**: дефолт был `false` (отсутствие ключа в localStorage
трактовалось как «показывать»). Теперь по умолчанию скрыты:
`localStorage.getItem('hideAcmeCerts') !== 'false'` — явное «false»
у пользователя, кто чекбокс отключал, сохраняется.

## Изменённые файлы

| Файл | Что |
|---|---|
| `frontend/src/components/OverviewTab.vue` | `caFilterOptions` из полного списка CA + провайдеров; дефолт `hideAcmeCerts = true` |

## Validation

- `vue-tsc` + `vite build` + vitest 36/36 — зелёные
- Внутренние CA теперь в фильтре независимо от наличия их сертификатов в
  списке; значение фильтра (`ca:<id>` / `acme:<id>`) не менялось — выбор
  пользователя живёт после обновления

## Ограничения (зафиксировано осознанно)

1. У не-админа ACME-провайдеры в фильтре появляются только если у него есть
   сертификаты такого провайдера (список провайдеров грузится только админам).
2. Пользователи, ранее явно отключавшие чекбокс, продолжат видеть ACME-серты
   (сохранённое `false` уважается).
