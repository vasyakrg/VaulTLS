# Report: роль «Admin» переименована в «Operator» (визуально)

- **Дата:** 2026-10-06
- **Профиль:** ui-copy
- **Статус:** Done

## Задача

Чисто визуальное переименование: роль `Admin` (по сути админ группы/сертификатов,
а не всего приложения) отображать как «Operator». Локальный админ остаётся
«admin» — его отображение нигде не привязано к этой роли.

## Решение

Роль хранится и передаётся как число (`UserRole::Admin = 1`, `Serialize_repr`),
именованные строки в API не участвуют — поэтому меняется только отображение:

- `frontend/src/locales/en.json`: `users.roleAdmin` «Admin» → «Operator»
- `frontend/src/locales/es.json`: «Administrador» → «Operador»

Эти ключи используются в единственном месте — `UserTab.vue`: тег роли в таблице
пользователей и опции в модалках создания/редактирования пользователя.
`fr.json` — частичная локаль (без секции `users`), правки не требует.

Внутренние идентификаторы (Rust `UserRole::Admin`, TS `UserRole.Admin`,
геттеры `isAdmin`/`isLocalAdmin`, права доступа) не менялись — затрагивается
только подпись. README (строка «Only admins can create new certificates»)
уточнён для консистентности.

## Изменённые файлы

| Файл | Что |
|---|---|
| `frontend/src/locales/en.json` | `users.roleAdmin` = «Operator» |
| `frontend/src/locales/es.json` | `users.roleAdmin` = «Operador» |
| `README.md` | формулировка про создание сертификатов |

## Validation

- `vue-tsc` + vitest 36/36 — зелёные; текст «Admin» в тестах и e2e не
  используется
- Бэкенд не менялся, прогон не требуется

## Ограничения (зафиксировано осознанно)

1. Наименование роли в коде и БД (`UserRole::Admin = 1`) сохранено — смена
   затронула бы миграции, API-контракты и зеркалирование прав во фронте ради
   одной подписи.
2. Надпись «Notify admins on new ACME certificate issuance» в настройках ACME
   не менялась: там речь о получателях уведомлений (включая OIDC-админов), а
   не о роли.
